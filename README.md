# Agent Clinic — מבצע: שגרה בריאה

## על הפרויקט

Agent Clinic הוא רעיון לאפליקציית ווב בעברית, שמטרתה לעזור לאנשים עובדים למצוא
רעיונות מעשיים לכושר ולארוחות בוקר וצהריים בריאות שאפשר לקחת לעבודה. העיצוב
יהיה נקי ומזמין, עם רמזים עדינים לעולם סוכנויות הביון — תדריכים ומשימות
בהומור מכבד, בלי שהנושא יאפיל על התוכן.

כיוון המוצר אושר כבסיס להמשך; היקף ה-MVP והמסכים יוגדרו במפרט פיצ'ר. לא
מתוכננים אבחונים, מעקב מחלות או ייעוץ רפואי.

## מצב הפרויקט

בשלב הנוכחי קיים שרת Hono מקומי מינימלי, המשמש לאימות התשתית לפני בניית
מסכי Agent Clinic. עדיין אין מסכי מוצר או מסד SQLite.

## טכנולוגיות מתוכננות

- TypeScript במצב Strict.
- Hono לשרת הווב.
- SQLite לאחסון מקומי, עם מיגרציות SQL כשיידרשו.
- Pico CSS מקומי, ללא תלות ב-CDN.
- תמיכה בעברית, RTL ותצוגה רספונסיבית.

הגרסאות ננעלו ב-`package.json` וב-`package-lock.json`: TypeScript `6.0.3`,
Hono `4.13.18`, מתאם Node `@hono/node-server` `2.1.8` וכלי הפיתוח. SQLite
ו-Pico CSS יתווספו בגרסאות מדויקות רק כשמפרט הפיצ'ר הרלוונטי יאושר.

## הרצה

נדרשת גרסת Node.js בטווח `>=24.13.0 <25`. התקנת התלויות, הבדיקות, בדיקת
הטיפוסים וה-Build אומתו. שרת הפיתוח זמין בכתובת
`http://localhost:3000/`:

```powershell
npm ci
npm run dev
npm test
npm run typecheck
npm run build
npm start
```

`npm run dev` מפעיל את השרת דרך `tsx`; `npm start` מפעיל את ה-Build האחרון.
הנתיב היחיד שהוגדר, `GET /`, מחזיר `Hello Hono!` כ-`text/plain`; נתיבים
אחרים מחזירים `404`. אם פורט `3000` תפוס, תוצג שגיאת הפעלה ולא ייבחר פורט
חלופי בשקט. בדיקות אוטומטיות בודקות את תגובת הנתיב הראשי ואת `404`.

# Agent Clinic — מבצע: שגרה בריאה

## על הפרויקט

Agent Clinic הוא רעיון לאפליקציית ווב בעברית, שמטרתה לעזור לאנשים עובדים למצוא
רעיונות מעשיים לכושר ולארוחות בוקר וצהריים בריאות שאפשר לקחת לעבודה. העיצוב
יהיה נקי ומזמין, עם רמזים עדינים לעולם סוכנויות הביון — תדריכים ומשימות
בהומור מכבד, בלי שהנושא יאפיל על התוכן.

כיוון המוצר אושר כבסיס להמשך; היקף ה-MVP והמסכים יוגדרו במפרט פיצ'ר. לא
מתוכננים אבחונים, מעקב מחלות או ייעוץ רפואי.

## מצב הפרויקט

כרגע קיים שלד TypeScript בלבד. עדיין אין מסכי מוצר, שרת Hono, מסד SQLite או
בדיקות אוטומטיות.

## טכנולוגיות מתוכננות

- TypeScript במצב Strict.
- Hono לשרת הווב.
- SQLite לאחסון מקומי, עם מיגרציות SQL כשיידרשו.
- Pico CSS מקומי, ללא תלות ב-CDN.
- תמיכה בעברית, RTL ותצוגה רספונסיבית.

גרסאות TypeScript וכלי הפיתוח ננעלו ב-`package.json` וב-`package-lock.json`.
גרסאות Hono, SQLite ו-Pico CSS ייקבעו במפרטים לפני הוספתן.

## הרצה

הפקודות הבאות נבדקו על שלד TypeScript. `dev` ו-`start` מציגות הודעת מוכנות;
הן אינן מפעילות עדיין שרת ווב:

```powershell
npm ci
npm run dev
npm run typecheck
npm run build
npm start
```

עדיין לא הוגדרה פקודת `npm test`; בדיקות אוטומטיות יתווספו יחד עם הפיצ'ר הראשון.

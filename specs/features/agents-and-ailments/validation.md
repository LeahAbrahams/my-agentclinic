# תוכנית אימות — Agents and Ailments

הפיצ'ר מוכן להשלמה רק לאחר PASS בכל שערי הקבלה. תוצאות בפועל יתועדו
ב-`TASKS.md`; הטבלה אינה טוענת שבדיקות שטרם הורצו עברו.

## שערים אוטומטיים

| תחום | אימות | תנאי PASS |
|---|---|---|
| התקנה | `npm ci` | קוד יציאה 0 ו-Lockfile תואם |
| מיגרציות | DB זמני/בזיכרון, מיגרציה פעמיים | כל הטבלאות קיימות; אין מיגרציה כפולה |
| Seed | ספירת Agents/Ailments/קשרים לפני ואחרי seed חוזר | לפחות 5 מכל סוג וקשר אחד לפחות; אין כפילויות |
| טיפוסים | `npm run typecheck` | ללא שגיאות |
| Build | `npm run build` | קוד יציאה 0 |
| בדיקות | `npm test` | כל בדיקות החוזה עוברות |
| אבטחת תלויות | `npm audit` | 0 חולשות פתוחות |
| דף הבית | `GET /` | HTTP 200, `lang=he`, `dir=rtl`, Header/Nav/Main/Footer |
| רשימת סוכנים | `GET /agents` | HTTP 200; שמות, מודל, מצב וקישורים |
| פרטי סוכן | `GET /agents/:id` קיים | HTTP 200; פרטי הסוכן וכל תקלותיו |
| פרטי סוכן חסר | `GET /agents/99999` | HTTP 404 |
| קטלוג תקלות | `GET /ailments` | HTTP 200; שמות ותיאורים |
| נכסים מקומיים | בקשות CSS | Pico וקובץ העיצוב המקומי מחזירים HTTP 200 |
| נתיב לא מוכר | `GET /not-a-route` | HTTP 404 |

## בדיקה ידנית בדפדפן

- בכל עמוד: Header, Nav, Main ו-Footer גלויים; קישורי ניווט עובדים.
- `/agents`: לפחות חמישה סוכנים, פרטי שדות תקינים, קישור ניתן להפעלה.
- פרופיל ידוע: סוג מודל, מצב וכל התקלות המתאימות.
- `/ailments`: לפחות חמש תקלות ותיאור לכל אחת.
- CSS נטען מהרשת המקומית; אין שגיאות בקונסול או בקשות CDN.
- ברוחבי 375px ו-1280px: אין גלילה אופקית, התוכן אינו נחתך, והניווט שמיש.
- תוויות מצב ופעולות בעברית; HTML מוגדר RTL; קישורים ניתנים להפעלה במקלדת.
- בדיקת HTML מוודאת שערכים מוצגים כטקסט ולא מוזרקים כתגיות.

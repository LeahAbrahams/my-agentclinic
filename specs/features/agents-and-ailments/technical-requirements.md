# דרישות טכניות — Agents and Ailments

מסמך זה משלים את [מפרט הפיצ'ר](./spec.md). הדרישות הטכניות מופרדות מתרחישי
המשתמש כדי לשמור על מפרט קריא, אך מחייבות באותה מידה.

## ממשק וטכנולוגיה

- **REQ-026**: הפרויקט MUST להישאר TypeScript עם `strict: true`; Props
  ציבוריים של רכיבי UI יוגדרו בטיפוסים עצמאיים, לא כטיפוסים inline.
- **REQ-027**: עיצוב MUST להשתמש ב-Pico CSS `2.1.1`, בגרסת classless,
  ובפלטת כתום/שחור. כל CSS MUST להיות מקומי; אין תלות ב-CDN.
- **REQ-036**: מסלולי הווב MUST להשתמש ב-Hono הקיים `4.13.18` ולהחזיר HTML
  server-rendered עם JSX של Hono; אין להוסיף framework צד-לקוח.
- **REQ-037**: כל HTML MUST להצהיר `lang="he"` ו-`dir="rtl"`; כל ערך נתון
  יוצג כטקסט מקודד, לא כ-HTML פעיל.
- **REQ-038**: הניווט, הסגנונות ותוכן הליבה MUST להיות זמינים ללא CDN או
  שירות חיצוני; נכסי העיצוב MUST להחזיר HTTP 200 מנתיב מקומי.

## התמדה ומודל נתונים

- **REQ-028**: התמדה MUST להשתמש ב-SQLite דרך `better-sqlite3` `13.1.1`,
  ללא ORM.
- **REQ-029**: קובצי מיגרציה MUST להתבצע לפי סדר שמי, כל מיגרציה בעסקה,
  ויישום MUST להיות אידמפוטנטי באמצעות רישום המיגרציות שהוחלו.
- **REQ-030**: Seeds MUST לרוץ לאחר המיגרציות ולהיות אידמפוטנטיים; יוגדרו
  פקודת seed נפרדת והכנת נתוני דוגמה בעת אתחול.
- **REQ-031**: טבלאות Agents, Ailments וקשר Agent-Ailment MUST לכלול
  Primary Keys, Unique ו-Foreign Keys בהתאם לישויות במפרט.
- **REQ-032**: שאילתות MUST להשתמש בפרמטרים; אין לשרשר מזהים או טקסט SQL
  ישירות.
- **REQ-033**: ערכים שהופקו מהמסד MUST להיות מקודדים בטקסט HTML. מזהי סוכן
  MUST לעבור ולידציה לפני חיפוש, ותוצאה חסרה MUST להחזיר HTTP `404`.

## בדיקות וגרסאות

- **REQ-034**: בדיקות אוטומטיות MUST לכסות מיגרציות, הרצה חוזרת, FK, seed,
  קשרים, נתיבים, `404`, Layout ונכסי CSS.
- **REQ-035**: `npm test`, `npm run typecheck`, `npm run build` ו-`npm audit`
  MUST להסתיים בהצלחה לפני סימון הפיצ'ר כהושלם.
- **REQ-039**: גרסאות תלויות ישירות MUST להיות מדויקות ולשמור Lockfile.
  `@types/better-sqlite3` `9.6.0` יינעל כתלות פיתוח.
- **REQ-040**: שגיאת DB או Migration בעת Startup MUST להירשם ולהכשיל את
  ההפעלה בגלוי; אסור לדווח שהשרת מוכן לאחר כשל.

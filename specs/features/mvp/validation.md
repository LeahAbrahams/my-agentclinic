# תוכנית אימות — MVP

המימוש ייחשב שלם רק לאחר התקנה נקייה וכל שערי האימות כאן. תוצאות שנאספו
לפני התקנה נקייה יסומנו היסטוריות ולא ייחשבו לתוצאות הנוכחיות.

## מסעות משתמש בדפדפן

1. בית → קטלוג סוכנים → פרופיל → טופס פגישה.
2. פגישה תקינה → אישור → Dashboard ורשומת פגישה.
3. קלט חסר או זמן שגוי → הודעת שגיאה וללא יצירה.
4. Dashboard → אישור/ביטול פגישה → ספירה/רשימה מעודכנת.
5. ניווט מתפריט לכל עמוד, קטלוג טיפולים, תקלות והמלצות.
6. נתיב שגוי → דף 404; בדיקת עמודי 500 דרך בדיקת `app.request`.

בכל מסע לבדוק 375px ו-1280px, שאין גלילה אופקית, שה-focus נראה, שהניווט
עובד במקלדת ושהקלט מוצג כטקסט בלבד. כל קובצי CSS מוגשים מקומית והתגובות
חייבות להיות HTTP 200.

## סביבת אימות

- **Infra**: SQLite זמני/בזיכרון; Docker אינו נחוץ למסד הנתונים המוטמע.
- **Browser**: הדפדפן האינטגרטיבי של VS Code זמין לבדיקות ידניות; אין
  להוסיף תלות Playwright אם כלי זה מכסה את המסע.
- **אחריות בדיקה**: כל קבוצת מימוש תריץ את שערי האימות ותתעד את תוצאותיהם.
  Build של Vercel משמש גם לאימות TypeScript/פריסה.
